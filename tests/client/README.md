# 客户端一键测试

真开一个 tModLoader 客户端，进测试世界，由模组里的自测把检查跑完、截图、写报告，然后自动退出游戏。

```
powershell -File _tools/client_test.ps1
```

退出码 0 = 全部通过，1 = 有失败，2 = 游戏开着没法测。会弹出游戏窗口，两段各约半分钟；测试期间键盘鼠标不影响游戏。
也可以挂在全量验证后面：`_tools/run_all.ps1 -Package -Client`。

## 为什么要它

离线测试（`tests/vmtest`、`tests/oracle`）只测核心逻辑，专用服务器测试（`_tools/verify_server.ps1`）只测「能加载、能进世界」。
贴图、放方块、图格实体、画布、在真实泰拉世界里施法、存档读档，这些只有客户端测得到。
它第一次跑就找到了几处离线和服务器测试都看不出来的问题，见 `AUDIT_VS_ORIGINAL.md`「客户端测试发现的问题」。

## 怎么跑的

1. 打包（`-NoBuild` 跳过，用上次打好的 .tmod）。
2. 世界用专用服务器测试生成的 `_verify/save/Worlds/_verify_world`；没有就先跑一遍 `verify_server.ps1`（`-FreshWorld` 重新生成）。
3. 独立的存档目录 `_verify/client/save`（`-tmlsavedirectory`）：只启用本模组，设置是测试专用的（1280x720 窗口、简体中文、静音），
   不碰玩家自己的存档、设置和别的模组。
4. **setup 段**：`-skipselect HexTest:_verify_world` 直接进世界（角色在加载完成时由测试建好），跑完以后存档、退出。
5. **verify 段**：再开一次读同一个存档，检查存下来的东西，最后把场地上的方块挖掉看掉落。
6. 汇总两段的报告和 `client.log` 里的错误。

只想重跑一段：`-Phase setup` / `-Phase verify`（verify 用上一次 setup 留下的存档）。

模组这一侧在 `HexCastingTerraria/Testing/`：`ClientTestSystem.cs` 是框架（只有带 `-hexclienttest` 启动时才加载，玩家正常玩时这几个类根本不存在），
`ClientTestCases.cs` 是检查内容。期望值一律按原版的规则写在测试里，不调用被测的换算代码去算。

## 测什么

| 段 | 节 | 内容 |
|---|---|---|
| setup | 环境 | 进了世界、单机、测试角色、游戏语言是简体中文 |
| setup | 贴图 | 本模组全部物品 / 方块 / 墙 / 增益 / 弹幕的贴图都加载了；运行时用游戏原图拼的几张（明晰 / 蒙翳 / 共振、深板岩）真的改了色，液体是原版效果色，蒙翳是减益的红框；物品和增益图标总览截图 |
| setup | 场地 | 出生点上空清出一块空地：最上面是施法区，下面每层放一排方块，背后是玻璃墙（挂墙的东西要有墙，玻璃墙不挡阳光） |
| setup | 放方块 | 模组里每一种能放的方块都照玩家放置的路子放一遍（TileObject.CanPlace / Place，再调放置后的钩子），要放得下；该有图格实体的要有 |
| setup | 施法 | 在真实世界里施法：施法者、脚底位置、视线、射线、破坏方块、放置方块（从法杖右边一格拿）、造水、召唤方块、推动掉落物、闪现、推自己，背包里的紫水晶粉被扣掉 |
| setup | 网格大小 | 明晰 / 蒙翳 / 探知透镜的网格大小照原版属性算；开着的画布跟着药效变；三张画布截图 |
| setup | 大法术石板 | 本世界的全部大法术（每个世界笔顺不同）各刻一块石板，排在场地顶上，放大截图 |
| setup | 存档 | 核心写进数据；石板刻图案、阿卡夏书架存一条、大挂轴框挂图案，各拍刻前刻后两张放大截图，比较像素确认图案画出来了；铺一块旧尺寸（2×2）的小挂轴框；存世界和角色 |
| verify | 存档读回 | 场地上的方块、图格实体、墙都在；核心、石板、书架、挂轴框里的数据一样；旧尺寸的挂轴框换成了 1×1、图案还在；大法术石板上还是本世界的笔顺（笔顺表跟着世界存档读回来） |
| verify | 挖方块 | 挖掉每一件：掉出放它的物品；石板、挂轴框带着图案掉；淬灵晶块照原版掉 2~5 片碎片，喝了共振药水拿镐挖掉方块本身 |

测试期间：时间固定在白天正午、不下雨、不刷怪，玩家不掉血、不受键盘鼠标影响；鼠标位置和镜头由测试指定
（视线就是鼠标方向；画布的网格点画在硬件鼠标旁边，只在画那一帧换成测试指定的位置）。

## 输出

都在 `_verify/client/out/`（不进仓库）：

- `report-setup.json`、`report-verify.json`：每一项检查（节、名字、通过没有、细节）、截图列表、附带信息（场地位置、总览截图的图标顺序、自定掉落的方块掉了什么）；
- `client-setup.log`、`client-verify.log`：这一段的 `client.log`；
- `*.png`：截图。`setup-gallery` 是物品和增益图标总览，`setup-arena-*` 是场地，`setup-canvas-*` 是三种网格大小的画布，
  `setup-slate*` / `setup-shelf*` / `setup-scroll*` 是刻图案前后的放大截图，`setup-great-spells` 是刻着本世界全部大法术的一排石板，`verify-arena-reloaded-*` 是读档后的场地。

## 已知噪音

- `Failed to load icon_small.png`：本模组故意不带这个文件（check_arch 第 10 条），客户端在模组列表里找它时记一条 WARN，不影响加载。
