# HexDebug（附属）

上游：[object-Object/HexDebug](https://github.com/object-Object/HexDebug) 0.9.0+1.20.1，MIT。

**是什么**：调试与编辑咒术。调试杖一步一步执行咒术、看栈和调用栈、断点；剪接台像文本编辑器一样编辑核心里的咒术；核心框架；22 个图案。

**开关**：模组配置「咒法学 · 附属兼容（服务端）」-> HexDebug。默认关；关着 = 没装。联机由开服的人决定，改了要重载模组。

**状态**：调试部分已做（P3a）——调试杖 / 淬灵调试杖（单步调试、逐过程、单步跳出、继续、重启、停止，潜行 + 滚轮换模式，淬灵的潜行 + Ctrl + 滚轮换线程）、运行杖 / 淬灵运行杖、断点图案与行断点、认知危害、调试杖之精思、两个「制作调试杖」图案、配方、书里的调试条目、游戏内调试面板。剪接台 / 制念台已做（编辑界面、25 个操作、撤销 / 重做、用法杖往里画图案、导出 .hexpattern、制念台施放融注的咒术、脑叶切除升级）；核心框架、16 个剪接图案、书里的剪接台条目、调试法术环还没做。功能与文件的对照见 `addon.json`。

**怎么用**：做一根调试杖（造物 + 充能紫水晶 ×3 + 金锭，铁砧），用「制作调试杖」封进咒术，或者空着拿、把装着咒术列表的核心放在快捷栏里它右边一格。使用一次开始调试，默认停在第一个 iota 之前；之后每用一次按当前模式走（潜行 + 滚轮换模式）。拿着它时屏幕右侧是调试面板：源码（当前行高亮，点一行设 / 取消断点）、栈、渡鸦之思、调用栈、输出。暂停时拿运行杖画图案，图案在调试中的栈上跑；潜行使用运行杖回到画之前。

## 与上游的偏差

- **调试信息在游戏内的调试面板里看**：上游的调试杖要先连上外部编辑器（VS Code + HexDebug 扩展，DAP 协议）才能用，栈、变量、源码、断点都在编辑器里。移植版不需要外部编辑器：调试会话随时可用，同样的信息画在屏幕右侧的面板里，行断点在面板里点行设置（默认「被求值时停」；上游编辑器里还能选「被转义时停 / 总是停」，面板里暂时只有默认这一种）。书里讲 VS Code 的那句照上游原文保留。外部调试服务器（DAP）最后做、默认关。
- **启动参数用上游的默认值**：在入口停、在出口不停、跳过内部帧、缩进 4、显示尾调用帧；上游由编辑器的 launch.json 给，移植版没有编辑器，固定用默认值。「未捕获的事故」默认捕获（上游编辑器默认勾选）。
- **「另一只手」是快捷栏里手上那格右边一格**：和本体所有手持物品类图案一样。
- **「调试杖智能潜行滚轮」（smartDebuggerSneakScroll）不移植**：上游是拿着调试杖、没在调试时把潜行滚轮让给副手的法术书；移植版潜行滚轮只认手上的物品，用不到。
- **配方材料**：金锭照搬；板岩方块用「任意板岩」；淬灵版用淬灵晶碎片 ×4 围住，原物品里的咒术、媒质、模式原样带过去（上游 flyswatter_quenching 配方）。合成台：调试杖用铁砧（和造物一样），运行杖和淬灵版用工作台（和法杖一样）。
- **剪接台界面像箱子**：上游是 MC 的容器界面（背包在下面）；这里打开时背包同时打开，槽位是泰拉的物品格子，面板放在背包下面（箱子的位置）。按钮上是短字，完整名字（官方译文）在悬停提示里。上游的剪接台快捷键（可配置）没有移植，用按钮和滚轮。
- **在剪接台里画图案用全屏画布**：上游在剪接台界面里开一个施法界面；移植版打开平时的全屏画布（法杖的图案先存起来，画完换回），画的图案送进剪接台，转义色 = 放进去了。
- **制念台**：脑叶切除 剪接台 + 哥布林工匠（同本体把「工具匠」映射成哥布林工匠）。上游会把村民的自定义名字给制念台；泰拉城镇 NPC 没有「改名」这回事，不移植。制念台施法用施法者自己的染色（上游可以给台子单独染色），施法冷却按帧计（上游 5 刻 = 15 帧）。
- **剪接台的选区、视野不随打开界面的人走**：和上游一样存在方块里，谁打开都看到同一个状态；撤销栈只在服务端内存里（上游也不存档）。
- **贴图**：上游 jar 里的 16×16 物品图放大两倍（_tools/gen_hexdebug_art.py）；调试杖的状态（封有咒术 / 调试中 / 步进模式）按上游模型分层叠画。
