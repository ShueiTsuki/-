# Hexcessible（附属）

上游：[tizu69/hexcessible](https://github.com/tizu69/hexcessible) 0.3.1，The JSON License。

**是什么**：施法界面的无障碍操作：键盘画图（q w e a d）、Ctrl+空格按名字搜索图案、给图案起别名、鼠标悬停看说明、按 N 查书。

**开关**：模组配置「咒法学 · 附属兼容（客户端）」-> Hexcessible。默认关；只影响自己，随时改。上游是纯客户端模组，联机时别人装不装都无所谓。

**状态**：只有入口和开关，功能还没做（ADDONS.md 的 P2）。功能与文件的对照见 `addon.json`。
