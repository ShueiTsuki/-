# Hexcessible（附属）

上游：[tizu69/hexcessible](https://github.com/tizu69/hexcessible) 0.3.1，The JSON License。

**是什么**：施法界面的无障碍操作：键盘画图（q w e a d）、Ctrl+空格按名字搜索图案、给图案起别名、鼠标悬停看说明、按 N 查书。

**开关**：模组配置「咒法学 · 附属兼容（客户端）」-> Hexcessible。默认关；只影响自己，随时改。上游是纯客户端模组，联机时别人装不装都无所谓。

**状态**：键盘绘制已做（q w e a d 画、s / 退格撤销、Enter / Tab / 空格 / 左键施放、h j k l / 方向键 / 鼠标移动、r / Shift+r / 滚轮旋转、右键退出，按键提示、虚影、提示框、左下角快捷键提示）。自动补全已做（Ctrl+空格，或按住一个点不动时直接打字；上下 / 滚轮选、左右翻书页、Enter / Tab 选中后进入键盘绘制放下）。别名已做（空闲时鼠标停在画好的图案上按 Ctrl+E，或补全里选中后按 Ctrl+E / F2；Enter / Tab 存下，清空再存 = 去掉别名）。悬停说明（停半秒）与手画时的提示已做。智能签名已做（补全里打数字给出画这个数的笔顺，2000 以内查表、更大的数或小数拆成几条再用幂 / 乘 / 加 / 除拼；打 v 和 - 给出簿记员之策略；画出来的数字 / 簿记员也能在提示里认出）。按 N 查书已做（空闲时按 N；鼠标停在画好的图案上就翻到讲它的那一页，否则打开首页；关书回到画布，图案还在）。显示选项已做（调暗UI、减少动效、完整显示点阵、渲染图案）。学会大法术已做（打开画布时另一只手拿着远古卷轴，就记下这个大法术在本世界的画法，之后补全里能选、画出来提示里认得）。只剩与 HexDebug 的联动（剪接台小画布），等 HexDebug 做完。功能与文件的对照见 `addon.json`。

## 与上游的偏差

- **按键按物理键位认，不按输入的字符**：上游用 Minecraft 的 charTyped（跟随键盘布局，输入法打开时会先进候选框）。这里读的是按键（Q W E A S D），中文输入法开着也能直接画；代价是 AZERTY 等布局下字母位置跟着 QWERTY 走。
- **配置项只放了已做功能用到的几项**（键盘绘制：启用 / 提示文本 / 按键提示 / 预览图案；快捷键提示；大写笔顺签名），默认值与上游一致；其余配置项随对应功能一起加。
- **学会的大法术按世界唯一 id 记**：上游单人按存档文件夹名、联机按服务器列表里的名字记；这里用世界的唯一 id，同一个世界改名、换服务器地址也还认得。存在 存档目录/Hexcessible/known_world_patterns.json，一行「世界 图案id 签名」与上游格式相同。没学会的大法术一律当不认识，不会借提示泄露本世界的画法。
- **提示框与字体**：上游用 Minecraft 的 drawTooltip（紫边深底）和 MC 字体；这里照着颜色画框，文字用泰拉的描边字。按键提示字母离终点的距离、提示框的偏移按 1 个格距换算（上游是固定 20 个界面像素）。
- **快捷键提示的顺序固定**：上游用 HashMap，顺序随哈希变；这里按代码里的顺序从下往上排。字体里没有箭头字形时，「←/↓/↑/→」写成 left/down/up/right。
- **自动补全的输入走泰拉的输入框**：上游只把敲的字符接到查询后面；这里用泰拉自己的文字输入（Main.GetInputText），所以能用中文输入法、Ctrl+V 粘贴、Ctrl+Z 清空，退格长按连删。Ctrl+退格删一个词照上游。
- **按名字搜的是中文名**：移植版的图案名只有官方中文名，英文界面也一样；英文可以按 id 里的词搜（如 get caster），和上游按 id 搜的规则一样（id 里的 : _ / 换成空格再匹配，所以要用空格）。
- **「输入名称……」不是斜体**：泰拉的字体没有斜体。
- **「副手」是快捷栏里手上那格右边一格**：泰拉没有副手，移植版本体所有「手持物品」类图案都这样认，学大法术也一样；红字说明照上游原文。
- **自动补全里右键仍然关画布**：上游 MC 施法界面右键什么都不做；移植版本体保留「右键关画布」，这里不拦。
- **全是空格时按 Ctrl+退格**：上游会抛异常（Stream.limit(-1)），这里删成空。
- **别名存在单独的文件里**：上游存在配置文件里（界面上不显示）；这里存在 存档目录/Hexcessible/aliases.json，同样全部世界共用。
- **转义四个图案不做成智能签名**：上游的 Escape 智能签名是因为原版里考察 / 内省 / 反思 / 消解不在动作注册表；移植版里它们是普通图案，所以只照上游在名字后面加符号（\ 、({ 、)} 、/），方便按符号搜。
- **数字与簿记员的名字用官方中文名**（「数字之精思：5.0」「簿记员之策略：-v」），和移植版其它图案名一致；簿记员的说明是 Hexcessible 自己的文字，跟随游戏语言。
- **上游会崩的几处边界不崩**：数字正好是 int 最小值时取绝对值越界、空查询生成簿记员，这里分别用 long 取绝对值、直接不给。其余附属（Hexical、HexThings、Overevaluate）的智能签名随那些附属，不移植。
- **按 N 翻到的页**：上游按「这个图案是条目里第几个图案页」传页码，条目里前面有文字页时会翻错；这里按图案页的锚点翻到正确的那一页。
- **「隐藏悬浮图案」（hideFloaties）不移植**：上游隐藏的是施法时绕着玩家转的那圈图案，移植版本体没有这个效果，开关无处可用。
- **「[Hexical] 阻止行走 / 阻止唤咒」不移植**：只对 Hexical 附属起作用，Hexical 不在移植范围内。
- **减少动效作用于所有画图案的地方**（画布、书、卷轴等），与上游一致（上游改的是 RenderLib.makeZappy）；只在 Hexcessible 开着时生效。
- **调试模式（debug）不移植**：上游的 debug 只在左上角打印状态名、在原点画绿点，属于开发用。
