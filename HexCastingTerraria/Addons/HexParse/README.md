# HexParse（附属）

上游：[YukkuriC/HexParseMod](https://github.com/YukkuriC/HexParseMod) 1.20.1-1.11.2，MIT。

**是什么**：在聊天栏用 `/hexParse <代码>` 把一段代码写进手上的核心 / 法术书，反过来也能把核心里的咒术读成代码；另有 8 个图案、注释 iota、宏与别名。

**开关**：模组配置「咒法学 · 附属兼容（服务端）」-> HexParse。默认关；关着 = 没装。联机由开服的人决定，改了要重载模组。

**状态**：只有入口和开关，功能还没做（ADDONS.md 的 P1）。功能与文件的对照见 `addon.json`。
